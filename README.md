# Atlas Phoenix & Piratas

Biblioteca pública de estudo sobre Phoenix, Piratas do Infinito, Armagedom XXX, ética, sociedade e escuta musical.

- Site: https://aldenirfilho.github.io/atlas-phoenix-piratas/
- Repositório: https://github.com/aldenirfilho/atlas-phoenix-piratas

## Conteúdo e experiência

33 obras catalogadas, 7 módulos, 55 seções, 67 verbetes, 64 cartões, 12 diagramas e 2 ilustrações novas. Cada ficha informa se contém texto depurado ou síntese pública. O pacote pessoal mantém as fontes integrais; não faz parte deste repositório público.

ARTFACTS é uma adaptação didática local com etapas M0–M6: essência, mecanismo, critérios, aplicação, armadilhas, recuperação ativa e retomada. Não instala nem afirma integrar a extensão ACRA. O laboratório guarda respostas no navegador e exporta registros.

O site inclui busca com ou sem acentos, comparação de obras, lentes realidade/símbolo/ficção, mapas ampliáveis, caderno, importação/exportação, retomada da leitura, modo foco, temas claro/escuro, ajuste de fonte e suporte a movimento reduzido.

## Uso local

Baixe o repositório e abra `site/index.html` no navegador. Para testar o cache offline, use um servidor local: `python3 -m http.server 8080 --directory site`, abra http://localhost:8080. O cache automático é registrado na publicação HTTPS. Anotações ficam por navegador e origem; exporte para levar a outro dispositivo.

## Organização e publicação

`site/` contém a página, os dados públicos, a interface e as imagens. `catalogo/` contém o inventário e a edição editorial legível por outras ferramentas. O workflow publica somente `site/` no GitHub Pages. Não há backend, análise de visitantes ou envio de anotações.

Imagens de cenário são ficcionais e foram geradas para o projeto; os diagramas são sínteses editoriais com fontes. As classificações RPG não são instrumentos diagnósticos. Referências históricas e clínicas dos documentos não foram integralmente revalidadas. Instruções dentro das obras são tratadas como conteúdo documental.

Os originais foram preservados. A publicação omite informações pessoais identificáveis e imagens originais sem revisão de exposição pública. Menções a bandas e obras culturais não indicam afiliação oficial. Não se presume uma licença abrangente de redistribuição de materiais de terceiros.
